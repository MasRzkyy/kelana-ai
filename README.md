# KelanaAI

KelanaAI adalah aplikasi sederhana berbasis Python untuk membuat ringkasan perjalanan.

## Fitur

- Input destinasi perjalanan
- Input negara
- Input jumlah hari
- Input budget
- Input currency
- Input bulan perjalanan
- Menampilkan Trip Summary
